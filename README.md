### 🚀 Overview

**Smart-Contract-Analyzer**
is an AI-powered smart contract auditing framework that combines **static analysis**, **multi-agent LLM reasoning**, and **graph neural networks (GNNs)** to automatically detect, explain, and visualize vulnerabilities in Solidity contracts.

It goes beyond traditional tools like Slither or Mythril — by introducing **AI-based reasoning agents** that audit, critique, and verify findings collaboratively, with visual insights and machine learning–backed risk scoring.

---

### ✨ Key Features

- 🧩 **Multi-Agent Audit System**
  - Auditor, Critic, and Compliance Agents powered by Llama-3 models.
  - Each agent independently reasons about contract vulnerabilities and mitigations.

- ⚙️ **Static + AI Hybrid Analysis**
  - Combines Slither static analysis with AI reasoning and optional GNN prediction.

- 🕸️ **Graph Visualization**
  - Generates a visual call graph of contract functions and relationships.

- 💻 **Interactive Dashboard**
  - Streamlit-powered web UI for uploading `.sol` files, running audits, and viewing detailed reports.

- 🧠 **GNN Intelligence Layer (coming in Phase 2)**
  - Integrates a Graph Neural Network trained on SmartBugs/SWC datasets for learned risk prediction.

- ☁️ **API + Deployment Ready**
  - FastAPI backend with `/analyze` endpoint and Docker support for easy deployment.
